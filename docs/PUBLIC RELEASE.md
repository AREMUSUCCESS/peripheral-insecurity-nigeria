# Public Release Checklist

This repository is intended to provide reproducible research materials while respecting the access and redistribution conditions of third-party datasets.

Before publishing the repository, verify that:

- no credentials, API keys, passwords, or private information are included;
- no personal computer paths or environment-specific files are included;
- raw ACLED data are not committed;
- NBS household-level microdata are not committed;
- raw WorldPop download archives are not committed;
- temporary files, debugging files, and Jupyter checkpoint files are excluded;
- the cleaned analysis notebook opens and runs from the documented project structure;
- repository and author metadata are correct;
- derived analytical outputs are permitted to be redistributed;
- the manuscript included in the repository corresponds to the final frozen research version;
- third-party datasets remain subject to their respective providers' access and use conditions.

The public repository provides the research code, documentation, permitted derived materials, and manuscript. Researchers requiring the underlying source datasets should obtain them directly from the relevant data providers.
