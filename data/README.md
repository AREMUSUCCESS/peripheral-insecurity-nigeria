# Data

Raw and restricted source datasets are intentionally not included in this public repository.

The analysis uses data from ACLED, the National Bureau of Statistics (NBS) Nigeria, WorldPop, and official Nigerian population projections. Researchers seeking to reproduce the analysis should obtain the relevant source datasets directly from the providers and follow their access, licensing, attribution, and redistribution requirements.

The repository may contain derived analytical outputs that do not reproduce restricted source records. Such outputs should be interpreted together with the methodology and source documentation.
